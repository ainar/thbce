### Q107 — ECS : fiches 9.21 et 9.22 (source sur eau) — refus code 3 maintenus le 18 novembre 2026

Annexe III fiches 9.21 (éq. 2156 à 2224) et 9.22 ; lot 1-ecs.

1. **9.21 (récupérateur de chaleur sur les eaux grises).** Refusée dans le lot 1-ecs ; implémentée au lot 1-ecs2 : voir `Q108.md`. Le refus code 3 est levé.
2. **9.22 (IdCET).** Les sources sur air sont implémentées (lot 6c). La source sur eau dépend de générateurs refusés (pompes à chaleur eau et sol, vague 2) : refus code 3 conservé.
3. **9.3 et 9.4.** Fiches d'assemblage sans équation : les cas pris en charge sont ceux de 9.1, 9.2 et des générateurs mixtes déjà modélisés ; les appoints décentralisés et la production mixte avec un générateur refusé restent refusés par la validation du générateur concerné.
