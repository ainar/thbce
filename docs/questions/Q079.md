### Q79 — Fiche 9.6, tableau 277 (A3 p. 1054) et tableau 279 (p. 1072) — lecture du lot 0c3, 18 novembre 2026

1. **Besoin unitaire de l'usage 16** (restaurants, 2 repas par jour, 6 jours sur 7). **Retenu** : le classeur des scénarios, **4,7 L par m² et par semaine** ; le tableau 277 écrit 19,5 (valeur de l'usage 13), incohérent avec l'usage 15 (5,3 dans les deux sources) et avec les 6 jours sur 7. Raison : « a est figé dans les scénarios conventionnels » (§9.6.3.2), le classeur fait foi des scénarios ; cohérence avec Q57. Aucun code propre à l'usage 16 : la valeur lue est celle du classeur transcrit (`thbce-data`, test `besoins_d_ecs_du_tableau_277`, qui consigne l'écart). Valeurs des six usages vérifiées par `usages_14_15_16_et_27` : 13 → 19,5 ; 14 → 2,2 ; 15 → 5,3 ; 16 → 4,7 ; 26 → 4,5 ; 27 → 9,8.
2. **Effet de la variante** (19,5 pour l'usage 16, **non exposée**). Restaurant de l'exemple (`restaurant-pac-ademe`) passé en usage 16, météo ADEME : avec 4,7, ECS 4 344 kWh et Cep 189,6 (valeurs assertées par `usages_14_15_16_et_27`) ; avec 19,5, ECS 13 607 kWh et Cep 242,9, soit +53,3 kWhep/(m².an) (+28 %) ; le Bbio ne change pas. Cette seconde mesure a été faite une fois en remplaçant temporairement la valeur du classeur ; elle n'est pas assertée, la variante n'étant pas exposée.
3. **Nombre de bouchons d'eau froide** (tableau 279, p. 1072, lu sur l'image) : 3 pour l'usage 16 (2 pour les autres usages de restauration : 13, 14, 15, 26 et 27). La valeur 3 de l'usage 16 est déjà dans le code (`nb_bouchons`) ; elle est lue ainsi sur l'image et paraît isolée parmi les restaurants (comme le 19,5, une coquille possible du texte) : conservée, faute de source contraire. Variante non exposée.
