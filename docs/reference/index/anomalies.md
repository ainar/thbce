# Anomalies de l'index du texte réglementaire

Fichier généré par `cargo run -p xtask -- index-texte`, ne pas modifier à la main.

Les anomalies décrivent ce que l'**extraction texte** ne permet pas de retrouver : numéros introuvables (équation affichée comme image, numéro coupé, légende absente), numéros en double, numéros hors séquence. Aucun numéro n'est déduit ni inventé : en cas de doute, lire l'image de la page (`cargo run -p xtask -- page`). Pour l'annexe II, la page est la page du PDF (la pagination imprimée a une page de retard).
